## Le problème

- Problème : Les étudiants trouvent confus et long le systeme de réservation de materiel.
- Persona : Les étudiants de TIM, c'est qu'ils veulent, c'est reduire le nombre de pas à faire, pour réserver le materiel, ce qui leur frustre est de réserver 48 heures avant

## La solution

- Proposition de valeur : Modificier directement les reservations sur tout appareil.
- Fonctionnalités du MVP : 
    - En tant que étudiant, je veux simplicier le systeme de reservation de materiel afin de aider aux autres étudiants, à avoir une systeme de reservation de materiel plus simple et rapide.
